# Textures Directory

REMANENCE generates procedural 2K and 1K dynamic heightmaps and textures for Earth, Moon regolith, and Mars sand ripples directly in memory via WebGL Canvas.

If you wish to provide NASA / LRO (Lunar Reconnaissance Orbiter) / HiRISE or Solar System Treks textures, you can place high-resolution maps here:
- `moon_displacement.jpg`
- `mars_elevation.jpg`
- `earth_daymap.jpg`
- `earth_clouds.jpg`
